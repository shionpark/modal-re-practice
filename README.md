# Modal Re-Practice

재사용 가능한 모달 컴포넌트

## 주요 기능
- 애니메이션 지원: 모달 열림 시 배경 fade out
- 외부 영역 클릭 닫기: 오버레이 클릭 시 모달 닫기
- Esc 키보드 제어: Esc 키로 모달 닫기

## 기술 스택
| 분류 | 기술 |
| -- | -- |
| 언어 | TypeScript |
| 프레임워크 | React |
| 스타일링 | Tailwind | 

## 설치 및 실행
```
git clone https://github.com/shionpark/modal-re-practice.git
cd modal-re-practice
pnpm install
pnpm dev
```
